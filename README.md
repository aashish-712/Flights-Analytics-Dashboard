# ✈️ Flights Analytics Dashboard

An interactive data analytics web application built using Python, Streamlit, MySQL, and Plotly.

## Features

- **Flight Search:** Search for flights between different source and destination cities.
- **Airline Analysis:** Visualize the number of flights operated by each airline using pie charts.
- **Busy Airport Analysis:** Identify airports with the highest flight activity using bar charts.
- **Daily Flight Trends:** Explore flight frequency over different journey dates using line charts.
- **Cloud Database Integration:** Connect to an Aiven-hosted MySQL database.

## Technologies Used

- Python
- MySQL
- MySQL Connector/Python
- Streamlit
- Plotly
- Pandas
- python-dotenv
- Aiven Cloud

## Project Structure

- `app.py` – Streamlit application and dashboard interface.
- `dbhelper.py` – Database connection and SQL query functions.
- `.env` – Environment configuration (not included in GitHub).
- `.gitignore` – Excludes sensitive and unnecessary files.

## Learning Objectives

This project demonstrates practical implementation of Python programming, SQL queries, database connectivity, data analysis, and interactive dashboard development.
